# Daily Content Planner
A simple planner and tracker for a daily short-video operation: YouTube Shorts (17/day) and Facebook Reels (8/day).
## Daily targets
- YouTube Shorts: 17 new Shorts/day
- Facebook Reels: 8/day on Page + 3/day on personal profile
- Text + image posts: 2/day Page + 2/day personal
## Golden hours (WIB)
- YouTube: 07:00, 08:00, 09:00, 12:00, 13:00, 16:00, 19:00, 20:00, 21:00, 22:00, 00:00, 01:00, 02:00, 03:00, 04:00, 05:00, 06:00
- Facebook Page (Europe): 13:31, 14:52, 18:24, 19:41, 00:19, 01:33, 02:47, 03:58
## Content rules
- Run exactly like a human: varied niches, titles, descriptions, durations (15-55s), staggered times.
- Every video MUST have audio (free-license music/SFX only).
- Candid concept: random, unique, funny animal behaviour, amateur style.
- Minimal on-screen text (small at edge or none).
- AI label ON for every post.
- Never violate TOS: no clickbait, no false claims, no bought engagement, no bots.
